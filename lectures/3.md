1. Измерение длины и копирование строк
• strlen(s) — возвращает длину строки s (не включая нуль-терминатор \0).
• strcpy(dest, src) — копирует строку src в буфер dest. Внимание: небезопасна, если dest меньше src.
• strncpy(dest, src, n) — копирует до n символов. Если src короче, заполняет остаток нулями. Не гарантирует \0 на конце, если лимит исчерпан.
• strcat(dest, src) — дописывает (конкатенирует) строку src в конец строки dest.
• strncat(dest, src, n) — дописывает до n символов из src в конец dest, всегда добавляя \0.
2. Сравнение строк
• strcmp(s1, s2) — сравнивает две строки лексикографически. Возвращает 0 (если равны), меньше 0 (если s1 < s2) или больше 0 (если s1 > s2).
• strncmp(s1, s2, n) — сравнивает только первые n символов строк.
3. Поиск в строках и токенизация
• strchr(s, c) — ищет первое вхождение символа c в строке s. Возвращает указатель на него или NULL.
• strrchr(s, c) — ищет последнее вхождение символа c.
• strstr(haystack, needle) — ищет подстроку needle в строке haystack.
• strspn(s, accept) — возвращает длину начального сегмента s, состоящего только из символов строки accept.
• strcspn(s, reject) — возвращает длину начального сегмента s, в котором нет ни одного символа из строки reject.
• strpbrk(s, accept) — находит первое вхождение любого символа из accept в строке s.
• strtok(s, delim) — разбивает строку на токены (части) по разделителям из строки delim. Функция изменяет исходную строку.
4. Работа с блоками памяти (заполнение и копирование void*)
Эти функции работают с сырыми байтами памяти и не обращают внимания на нуль-терминатор \0:
• memset(dest, c, n) — заполняет первые n байт памяти символом c (часто используется для обнуления массивов и структур: memset(&arr, 0, sizeof(arr))).
• memcpy(dest, src, n) — копирует n байт из src в dest. Области памяти не должны перекрываться.
• memmove(dest, src, n) — копирует n байт из src в dest. Работает корректно, даже если области памяти перекрываются.
• memcmp(s1, s2, n) — сравнивает первые n байт двух блоков памяти.
• memchr(s, c, n) — ищет первое вхождение байта c в первых n байтах блока памяти.
