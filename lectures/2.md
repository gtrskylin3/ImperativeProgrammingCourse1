strlen(const char* s) — вычисляет длину строки. Возвращает количество символов в строке s, не считая завершающий нулевой символ ('\0').

strcmp(const char* s1, const char* s2) — сравнивает две строки посимвольно (в алфавитном порядке / по кодам ASCII). Возвращает 0, если строки абсолютно одинаковы. Если первая строка "меньше" второй — возвращает отрицательное число, если "больше" — положительное.

strcpy(char* dest, const char* src) — копирует строку. Перезаписывает содержимое строки dest, полностью копируя туда строку src вместе с её нулевым символом. Важно: dest должен иметь достаточно места, иначе программа сломается.

strcat(char* dest, const char* src) — объединяет (конкатенирует) строки. Дописывает строку src в самый конец строки dest. Старый нулевой символ в конце dest стирается, а новый ставится уже после добавленного текста.
